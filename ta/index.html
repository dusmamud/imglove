கணக்கு தேவையில்லை

Image Quill-இன் அனைத்து கருவிகளும் இலவசம் மற்றும் உங்கள் உலாவியிலேயே நேரடியாக இயங்கும் — பதிவு இல்லை, உள்நுழைவு இல்லை, எப்போதும் இல்லை.

படங்களுடன் வேலை செய்ய தேவையான அனைத்து கருவிகளும்

உங்கள் படங்களை ஆன்லைனில் சுருக்குங்கள், அளவை மாற்றுங்கள், செதுக்குங்கள், மாற்றுங்கள், திருத்துங்கள். இலவசம், வேகமானது, பாதுகாப்பானது — உங்கள் உலாவியிலேயே.

சுருக்கு IMAGE தரத்தை இழக்காமல் உங்கள் படங்களின் கோப்பு அளவைக் குறைக்கவும். அளவை மாற்று IMAGE பிக்சல் அல்லது சதவீதத்தில் உங்கள் படங்களின் பரிமாணங்களை மாற்றவும். செதுக்கு IMAGE உங்கள் படங்களிலிருந்து சரியான சட்டத்தை வெட்டி எடுக்கவும். மாற்று IMAGE JPG, PNG, WEBP உட்பட பல வடிவங்களுக்கிடையே படங்களை மாற்றவும். சுழற்று IMAGE உங்கள் படங்களை இடது, வலது பக்கம் சுழற்றவும் அல்லது திருப்பவும். நீர்க்குறி IMAGE உங்கள் படங்களைப் பாதுகாக்க உரை நீர்க்குறியைச் சேர்க்கவும். மீம் உருவாக்கி மேலும் கீழும் வசனங்களைச் சேர்த்து வினாடிகளில் மீம்களை உருவாக்குங்கள். புகைப்படத் திருத்தி வடிப்பான்களைப் பயன்படுத்தி ஒளிர்வு, மாறுபாடு போன்றவற்றைச் சரிசெய்யவும். பெரிதாக்கு IMAGE தரம் இழக்காமல் படங்களை 4x வரை பெரிதாக்குங்கள். மங்கல் IMAGE உணர்திறன் பகுதிகளை மறைக்க அல்லது விளைவுகளுக்காக படங்களை மங்கலாக்குங்கள். வளைந்த மூலைகள் உங்கள் படங்களுக்கு மென்மையான வளைந்த மூலைகளைக் கொடுங்கள். பார்டர் சேர் உங்கள் படங்களைச் சுற்றி வண்ண பார்டரைச் சேர்க்கவும். பிரி IMAGE உங்கள் படத்தை சிறு ஓடுகளின் கட்டமாக வெட்டுங்கள். பின்னணி நீக்கி ஒரே கிளிக்கில் புகைப்பட பின்னணியை நீக்குங்கள். படம் PDF ஆக உங்கள் படங்களை ஒரே PDF ஆவணமாக இணைக்கவும். ஃபேவிகான் உருவாக்கி உங்கள் படத்திலிருந்து அனைத்து அளவு ஃபேவிகான் ஐகான்களை உருவாக்குங்கள். படம் உரையாக OCR மூலம் படங்களிலிருந்து உரையைப் பிரித்தெடுக்கவும். GIF உருவாக்கி உங்கள் படங்களிலிருந்து அனிமேஷன் GIF உருவாக்குங்கள். HTML படமாக உங்கள் HTML குறியீட்டை PNG படமாக மாற்றுங்கள்.

இந்த பட கருவிகள் உண்மையிலேயே இலவசமா?

ஆம். Image Quill-இல் உள்ள அனைத்து கருவிகளும் முற்றிலும் இலவசம் — மறைக்கப்பட்ட வரம்புகள் இல்லை, உங்கள் படங்களில் நீர்க்குறி இல்லை.

என் படங்கள் சேவையகத்தில் பதிவேற்றப்படுமா?

இல்லை. ஒவ்வொரு கருவியும் நவீன வலை தொழில்நுட்பத்தைப் பயன்படுத்தி உங்கள் உலாவியிலேயே முழுமையாக இயங்குகிறது. உங்கள் கோப்புகள் உங்கள் சாதனத்தை விட்டு வெளியேறாது.

எந்த பட வடிவங்கள் ஆதரிக்கப்படுகின்றன?

உள்ளீட்டிற்கு JPG, PNG, WEBP, GIF, AVIF மற்றும் HEIC (iPhone புகைப்படங்கள்). JPG, PNG அல்லது WEBP ஆக ஏற்றுமதி செய்யலாம்.
